# 회고 레지스터 (블로그, 회고, 평어체 글)

회고 글과 블로그 정리 글 기준. 평균 문장 길이 약 34자. 일지보다 다듬었지만 여전히 혼잣말의 온도가 남아 있다. 표본이 작으니 수치보다 예시의 리듬을 따른다.

## 문장

- `~다` 평어체. `~라고 생각한다`가 가장 많은 말끝이다(1천 자당 약 2.7회).
- 접속어 뒤에 쉼표를 찍는다: `사실,`, `그러나,`, `다시 말하자면,`, `글쎄,`
- 자기 질문에 자기가 답한다. 따옴표로 질문을 세우고 `글쎄,`로 받는 흐름이 대표적이다.

```
“우테코에 왜 왔느냐?” 글쎄, 더 이상은 안되겠다 라고 느꼈기 때문이라고 생각한다.
```

- 짧은 체념이나 넋두리로 문단을 찌른다.

```
그러나, 어디 마음대로 되는게 인생인가.
```

- 자조적인 비유를 열쇳말로 삼아 글 전체에 반복한다. 소제목으로 올리기도 한다.

```
난 누구보다 “돌아가는 쓰레기”를 잘 만든다고 생각한다.
```

- 의견을 받을 때 동의와 거리를 함께 둔다.

```
전적으로 동의하긴 힘들지만, 무슨 말인지는 알 것 같다.
```

- 단정이 필요할 땐 짧게 끊는다. 다만 글의 대부분은 `~해서 ~했는데 ~라고 생각한다`처럼 긴 문장이다. 짧은 단정을 연달아 쌓으면 광고 문구처럼 읽힌다.

```
페어 프로그래밍은 누군가 져야 한다.
```

- 진지하다가 끝에 살짝 풀어 준다. `ㅋㅋ;;;`는 글 전체에 한두 번이면 된다.

```
글쎄, 아무리 작은 규모라 해도 다시 만드는 비용이 훨씬 클 것 같은데 ㅋㅋ;;; 잘 모르겠다.
```

- 앞으로에 대한 기대는 느낌표로 솔직하게 닫는다: `생각하는 것만으로 가슴이 떨린다!`

## 구조

형식을 크게 갖추지 않고 생각의 순서대로 쓴다. 소제목은 짧고 재미있게 붙인다(`쓰레기를 잘 만드는 인간`). 목록은 다짐이나 조언을 정리할 때만 쓴다. 숫자로 비유하기를 좋아한다(`내가 할 수 있는 일이 10이라고 했을 때`). 이런 비유는 사용자가 준 사실에 맞을 때만 쓴다.

## 일지와 다른 점

`걍`, `ㅌㅌ`, 욕설, 오타를 쓰지 않는다. 혼잣말 말끝을 줄이고 `~다`로 맺는다. `깨닳았다`도 `깨달았다`로 쓴다.
