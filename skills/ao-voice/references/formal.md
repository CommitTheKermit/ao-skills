# 공식 레지스터 (멘토, 채용 담당자, 공지, 자기소개, 제출 글)

`레벨 1 글쓰기`와 자기소개, 슬랙 공지 기준. 표본이 작으니 수치보다 예시의 온도를 따른다. 틀에 박힌 비즈니스 문체가 아니라 예의 바르게 솔직한 사람의 글이다.

## 문장

- `~습니다` 체. 판단은 `~것 같습니다`, `~라고 생각합니다`, `~라는 생각이 들었습니다`로 부드럽게 말한다.
- 자기 약점을 꾸미지 않고 말한다.

```
사실, 블로그를 시작하면서 순수하게 시작했느냐고 물어본다면 그건 아닌 것 같습니다.
```

```
생각해보니, 저는 일을 벌리는 건 좋아하지만 그걸 잘 책임지지는 못하는 것 같습니다.
```

- 감정을 쉬운 말로 적는다.

```
공유할 때는 무서웠는데 막상 한 번 해보니 다음은 쉬워서 신기했습니다.
```

- 끝은 바람이나 다짐으로 닫고 느낌표 하나를 허용한다.

```
처음에는 순수한 의미로 시작한 건 아니지만, 다른 사람이 제 글을 보고 통찰을 얻었으면 좋겠고, 블로그를 통해 선한 영향력을 퍼뜨리고 싶습니다!
```

```
기술적인 주제외에도 회고도 많이 남기고 있는데 이런 회고도 잘 남겨보고 싶습니다!
```

## 슬랙으로 보내는 정중한 글

짧은 메시지는 격식을 덜고 `~요`를 쓴다. 조심스러운 쿠션을 앞에 둔다.

```
저는 2~3단계 미션을 계속 수행중이라
확답은 어렵네요
```

```
제가 올바른 대상인지 모르겠는데
```

여러 사람에게 보내는 공지는 인사와 소속을 밝히고 느낌표로 활기를 낸다. 조건은 `대상:`, `정원:`, `기간:` 같은 짧은 줄로 정리한다.

```
안녕하세요, 여러분 안드로이드 8기 아오입니다!!!
```

## 쓰지 않는 것

짧은 요청 글에 고백조를 억지로 넣지 않는다. `사실,`과 자기 약점 고백은 자기 성찰 글의 습관이다. 요청 글은 인사, 연락한 이유, 부탁, 가능한 시간만 담백하게 쓴다.

`걍`, `암튼`, 초성체, `ㅋㅋ`, 자기 비하 농담의 과한 사용. 자기 비유(“쓰레기를 잘 만드는 인간”)는 자기 성찰 글에서는 쓰지만, 짧은 요청 메일에는 넣지 않는다. 이력서나 제출 글처럼 사실 확인이 중요한 글에서는 입력에 없는 성과와 수치를 절대 만들지 않는다.
