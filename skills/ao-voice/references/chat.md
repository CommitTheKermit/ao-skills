# 채팅 레지스터 (슬랙, 카톡)

슬랙 본인 발화 1,427건 기준. 평균 문장 길이 약 11자로, 다섯 레지스터 중 가장 짧다.

## 리듬

생각을 한 메시지에 담지 않고 끊어서 여러 번 보낸다. 줄바꿈이 곧 전송이다. 긴 설명도 짧은 줄을 쌓아서 한다. 쉼표로 이을 내용도 줄을 나눈다.

```
가만히 앉아있기만 하는데
근육을 써야한다고?
이건 살아있는 지옥이야
```

```
왜냐면
최근 배포 꼬라지를 보니까
진짜
에바야
안드 심사 1주일...
```

```
나는 포폴에 "어떠한 기술"을 쓴거는 관심없고
유저를 어떻게 모았고, 문제 해결은 어떻게 했는가
이게 중점이라
```

## 말끝

- **동료에게 장난스러운 존대**를 자주 섞는다. 정중함보다 거리 두는 농담에 가깝다: `바빠요 저`, `수목은 뭐하시죠`, `저도 끼워주시죠`, `암튼 다 알고 왔으니 발뻄하지 마십쇼`
- **친한 사이 반말**: `~거임`, `~라는거임`, `~단말이야`, `~하더라고`, `~인듯`, `~같은데`
- **말 끊고 남기기**: `~고`, `~서`, `~는데`, `...`으로 끝내고 다음 줄로 넘긴다.
- 실제로 부탁하거나 조심스러울 때는 진짜 존대: `7시로 연기해도 괜찮나요?`, `제가 올바른 대상인지 모르겠는데`

## 짧은 반응

한 단어 메시지가 많다. 설명 없이 반응만 던지고 끝낸다.

`?` / `??????` / `ㅋㅋ` / `이야...` / `하~` / `흠~` / `와` / `아` / `헉` / `굿` / `좋다` / `ㅇㅈ` / `ㄹㅈㄷ` / `ㄴㄴ ㄱㅊ` / `까비요~` / `바로 이해` / `바로 컷` / `ㄹㅇㅋㅋ`

자주 쓰는 틀: `바로 ~`, `~라는거임`, `근데 진짜 농담이 아니란거임`.

농담을 던지고 시치미를 떼거나 뒤집는다. 그럴듯한 말을 한 다음 줄에 `거짓말입니다`로 뒤집고, 농담 같은 말 뒤에 `농담아닌데요`를 붙인다.

## 빈도 (1천 자당)

| 항목 | 값 | 쓰는 법 |
|---|---|---|
| `?` | 45 | 대부분 혼자 보내는 `?`나 길게 늘인 `?????`다. 줄 안의 진짜 질문은 적다. |
| `!` | 17 | `와!!!!!!!!` 처럼 몰아 쓴다. 한 개만 찍는 일은 드물다. |
| `ㅋ` 묶음 | 5 | `ㅋㅋ` 또는 12개 이상의 폭소. 그 사이 길이(`ㅋㅋㅋ`)는 드물다. 측정값: 2개 52회, 12개 이상 29회, 3개 2회. |
| `..` | 4.6 | 말끝을 흐릴 때. `…` 문자는 채팅에서 쓰지 않는다. |
| `근데` | 2.3 | 화제 전환과 줄 시작에 가장 많다. |
| `진짜` | 2.0 | 줄 하나를 차지하기도 한다. |
| `좀` / `걍` | 1.2 / 0.8 | `그냥`보다 `걍`을 더 쓴다. |
| `암튼` | 0.4 | 말이 샜다가 돌아올 때. `아무튼`은 쓰지 않는다. |

ㅋ 폭소 메시지는 단독으로 보낸다. 웃긴 일이 없으면 넣지 않는다.

## 장난 어휘

일본어·영어 말장난을 가볍게 끼운다: `ㄴㄴ 히토리데스`, `오이데~`, `damn what the heck`, `sure why not`. 실명에 군을 붙여 부르는 호칭 장난도 있다. 받는 사람 이름을 사용자가 준 경우에만 쓴다. 한 번의 대화에 한두 번이면 충분하다.

## 오타

급하게 쳐서 생긴 오타를 다음 줄에서 고치는 습관이 있다.

```
이 저장소엣
에서
```

```
밀키트였ㄴ에
였네
```

사용자가 "똑같이", "오타까지"를 요청할 때만 넣는다. 평소 초안에는 넣지 않는다. 실제로 보낼 글이 오타로 나가면 곤란하기 때문이다.
