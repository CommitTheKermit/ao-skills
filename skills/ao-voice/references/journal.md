# 일지 레지스터

노션 일지 약 70건 기준. 평균 문장 길이 약 32자. 남에게 보이지 않는 글이라 가장 날것이다.

## 구조

제목은 `0714화`처럼 날짜+요일이고, 본문은 `아침`, `오전`, `점심`, `오후`, `저녁` 다섯 시간대 소제목으로 나눈다. 소제목에 마크다운 기호를 달지 않는다. 쓸 게 없으면 없다고 쓴다: `별로 쓸 게 없네 오늘은`.

- **아침**: 전날 잠, 컨디션, 출근 수단 이야기.
- **점심**: 무엇을 먹었고 맛이 어땠는지 거의 매일 쓴다. 메뉴를 사용자가 주지 않았으면 지어내지 말고 비워 둔다.
- **오후·저녁**: 사건에서 시작해 생각으로 길어진다. 생각이 깊어지면 몇 문단 이어지고, 결론 없이 끝나도 된다.

행사나 특강 메모가 끼면 그 부분만 번호 목록과 `→`로 쓰고 다시 평문으로 돌아온다.

## 문장

평어체 `~었다`, `~했다`, `~같다`, `~겠다`, `~싶다`가 뼈대다. 여기에 혼잣말이 불쑥 끼어든다. 이 섞임이 일지의 핵심이다. 깔끔한 평어체로만 쓰면 닮지 않는다.

```
점심은 소바+튀김인데 늦게가서 그런가 메뉴도 늦게 나오고 소바인데 밀가루면이라서 걍 국수였다. 콘치즈+콘샐러드로 배채우고 ㅌㅌ
```

```
나는 1시간 가량 더 있었는데 뇌 리소스가 모두 소진되어서 있으나마나 한 시간이었다. 그냥 빨리 갈걸 ㅋㅋ
```

```
스터디까지 자전거 타고 가려고 했는데 생각해보니 비가 엄청 온다고 해서 포기;;; 충전만 해놓게됐네
```

- 혼잣말 말끝: `~네`, `~지`, `~나`, `~잖아`, `~임`, `~을듯`, `흠…`, `에휴`
- 체념은 물결로 끝낸다: `잠을 오래 자고 싶은데 그럴 수가 없다, 어찌해야할지~`
- 자문: `왜 아무 생각이 안나지 별일 없었나?`
- 다짐으로 닫기: `작은 실험을 통해 개선해보던가 해야겠다.`, `그래도 해보자`
- 사건 나열은 `~했는데 ~했고 ~해서`로 길게 잇는다. 한 문장이 2~3개 사건을 담는다. 이것이 가장 중요한 리듬이다. 사건마다 문장을 끊으면 메모처럼 읽혀 닮지 않는다. 입력이 단어 나열이어도 주어진 사건끼리 `~했는데`, `~해서`로 잇고, 말끝을 평어체와 혼잣말로 섞는다. `늦잠을 자서 지하철을 탔다.`처럼 교과서 같은 평어체로만 두면 실패다.
- 하루를 교훈으로 정리하지 않는다. 고민은 고민인 채로 두고 끝나도 된다.

생각이 무르익으면 짧은 단정문이 연달아 나온다.

```
AI는 자연재해다. 개발자가 피하고 싶다고 해서 피할 수 있는 게 아니다. 피할 수 없다면, 즐겨라.
```

자주 쓰는 틀: `~라는 생각이 들었다`, `~라는 생각이 많이 들었다`, `~인 것 같다`, `암튼,`, `근데 뭐…`.

## 표기 습관

일지에서는 그대로 살린다.

- 붙여쓰기: `~하는거`, `~인것같다`, `~한게`
- 고정 표기: `깨닳았다` (코퍼스에 `깨달았다` 없음), `걍`
- `…`를 슬랙보다 더 쓴다.
