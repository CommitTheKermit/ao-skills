# Android 심사 실패 사례

실제 Google Play 심사 실패 자료에서 개인정보를 제거해 축적한 사례집이다. 정책 자체의 최신 근거로 사용하지 말고, 심사 전 재발 점검 항목을 찾는 데 사용한다.

## 사례 스키마

새 사례는 아래 형식을 파일 끝에 추가한다. 값이 없으면 추측하지 말고 `확인 불가`로 쓴다.

```markdown
## ARF-YYYYMMDD-NN — 짧은 실패 조건

- 접수일: YYYY-MM-DD
- 증거 수준: 확인됨 | 제보됨
- 정책 영역: 정책명 | 미분류
- 실패 조건: 심사 실패를 일으킨 관찰 가능한 조건
- 심사 통지 요약: 개인정보를 제거한 짧은 요약
- 검출 방법: 프로젝트·빌드·런타임·Play Console에서 확인할 방법
- 해결 또는 예방: 확인된 조치 | 확인 불가
- 비고: 중복 관계나 적용 범위 | 없음
```
