# 홈서버 원격 작업

<!-- usage-stats: skill home-server -->

첫 동작으로 아래 명령을 이 발동에서 한 번만 실행한다.

```bash
python3 "$HOME/.agents/skills/usage-stats/scripts/usage_stats.py" record skill home-server >/dev/null 2>&1 || true
```

## 공개 원본과 로컬 설정 분리

스킬 원본은 공개될 수 있다. 호스트명, IP, 사용자명, 프로필·저장소 절대경로, 호스트 키 지문,
개인키 경로, 토큰과 환경변수 값은 스킬·프로젝트 파일·커밋·응답에 기록하지 않는다.
접속 정보는 Git 밖의 `~/.ssh/config`에 둔 `home-server` 별칭을 사용한다. 별칭이 없거나
호스트 키 검증이 실패하면 값을 추측하거나 `StrictHostKeyChecking=no`로 우회하지 말고 중단한다.

## 작업 시작

요청에서 결과를 바꾸는 항목만 짧게 재진술한다: 수행 작업, 대상 프로젝트·브랜치·서비스,
변경 산출물, 기준 문서 또는 코드, 제외 범위. 서버가 명확하지 않으면 먼저 확인한다.

다음 순서로 접속 가능성과 원격 정체성을 확인한다.

```bash
ssh -o ConnectTimeout=10 home-server "hostname && whoami"
```

명령은 기본 셸이 `cmd.exe`일 수 있다고 가정한다. Windows 상태 확인과 변경은
`powershell -NoProfile -Command`로 명시한다. 복잡한 스크립트나 사용자 입력을 셸 문자열에
직접 보간하지 않는다. 비밀값은 명령 인자, 표준 출력, 로그에 넣지 않는다.

## 변경 전 점검

- 장치 시간, Tailscale·OpenSSH 상태와 실제 대상 경로를 읽기 전용으로 확인한다.
- 프로젝트 작업이면 `git status --untracked-files=no`, 현재 브랜치, remote를 먼저 확인한다.
  추적 중인 기존 변경을 새 작업과 섞지 않으며, 깨끗하지 않으면 내용을 파악해 보고한다.
- 프로젝트 경로를 사용자 프로필명으로 조합하지 않는다. 원격의 문서나 기존 checkout에서
  실제 경로를 확인한다.
- 환경변수·인증은 존재 여부와 필요한 범위의 성공 여부만 검사한다. 값을 출력하지 않는다.
- 서비스와 예약 작업은 정확한 이름·실행 사용자·동작·트리거·최근 결과를 먼저 읽는다.

## 작업 수행

사용자가 요청한 범위의 변경은 추가 승인 없이 이어서 완료한다. 저장소의 AGENTS.md와 운영
문서를 코드보다 먼저 확인하되, 실제 코드와 현재 시스템 상태를 최종 근거로 삼는다.

- Git 변경은 기존 작업 브랜치를 재사용하고, pull 전 작업 트리와 원격 차이를 확인한다.
- 실행 중인 정상 서비스와 예약 작업은 재사용한다. 소유자를 확인하지 않은 프로세스 종료,
  포트 일괄 종료, 강제 초기화는 하지 않는다.
- 예약 작업을 만들거나 고칠 때 실행 계정, working directory, 환경변수 가시성, 중복 실행,
  재시도, 절전 복귀와 종료 코드를 함께 확인한다.
- 재부팅, SSH 패키지 제거, 방화벽 차단처럼 현재 복구 경로를 끊는 작업은 직전에 사용자 허락을
  받는다. 재부팅은 로컬 화면이나 별도 복구 경로가 확보된 경우에만 한다.
- 서비스 계정 파일, 개인키, 토큰, 암호를 읽어 출력하거나 저장소로 복사하지 않는다.

## 완료 검증

설정값만 보고 완료하지 않는다. 요청과 직접 연결된 실제 증거를 확인한다.

- 서비스: 프로세스·리스너와 로컬 또는 허용된 경로의 실제 응답
- 예약 작업: 등록 설정, 수동 실행 결과, 최근 종료 코드. 정기 실행을 요청했다면 실제 예약 시각
  실행 결과까지 확인하고 수동 실행만으로 대체하지 않는다.
- 배치: 기대 산출물의 갱신 시각·행 수·중복 조건과 외부 반영 상태
- Git: 최종 branch, commit, `git status --untracked-files=no`

실행하지 못한 항목과 이유를 완료 항목과 분리해 보고한다. 접속 주소, 사용자명, 지문, 비밀값은
최종 응답에 반복하지 않는다.
