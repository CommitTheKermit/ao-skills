# 문서 작성과 메모리 라우팅

<!-- usage-stats: skill document-memory-routing -->

첫 동작으로 `python3 "$HOME/.agents/skills/usage-stats/scripts/usage_stats.py" record skill document-memory-routing >/dev/null 2>&1 || true`를 이 발동에서 한 번만 실행한다. 기록 도구가 없어도 문서 작업은 계속한다.

문서의 저장과 후속 에이전트가 그 문서를 찾는 경로를 같은 작업으로 완료한다. 여기서 프로젝트 메모리는 프로젝트의 `AGENTS.md`이며, 자동 생성되는 Codex memories 폴더를 의미하지 않는다.

## 적용 범위

- 사용자가 요청한 지속 보관 문서와 구현 작업에 수반되는 설계, 요구사항, 제약, 운영, 인계 문서에 적용한다. 별도 스킬 호출이나 knowledge-loop 후보 승격을 기다리지 않는다.
- 읽기 전용 요청, 채팅 안의 설명, 임시 초안, 빌드 로그, 자동 생성 파일, 비밀값이 든 파일은 라우팅하지 않는다. 사용자가 라우팅을 제외했다면 그 범위를 따른다.
- 프로젝트 문서는 해당 프로젝트에 연결한다. 프로젝트가 없는 전역 문서는 이미 지정된 문서 볼트의 인덱스나 전역 AGENTS.md의 관련 지식 라우팅에 연결한다. 저장 위치나 소유 프로젝트를 판단할 수 없을 때만 질문한다.

## 작업 절차

1. 문서를 소유한 프로젝트, 적용되는 AGENTS.md, 기존 문서 위치 및 관련 README나 인덱스를 확인한다. 작업 중인 체크아웃을 기준으로 하며 다른 작업 브랜치의 파일과 섞지 않는다.
2. 기존 문서가 같은 주제를 담당하면 갱신한다. 상세 내용과 근거, 확인일, 미확인 사항은 문서에 둔다. 문서 위치는 프로젝트의 기존 규칙을 따른다.
3. 문서 작성 또는 갱신과 함께 AGENTS.md의 관련 절에 `어떤 작업을 할 때 + 어느 문서를 먼저 읽는지`를 1~2줄로 추가하거나 갱신한다. 저장만으로 끝내거나 README 링크를 AGENTS.md 라우팅으로 대신하지 않는다. 기존 라우팅이 충분하면 중복 추가하지 않는다.
4. 하위 AGENTS.md를 사용할 때는 그 문서를 필요로 하는 작업에서 실제로 읽히는 범위인지 확인한다. 여러 영역에 걸친 문서는 프로젝트 루트에 연결한다. 파일이 없으면 프로젝트 루트에 최소 AGENTS.md를 만든다. 심볼릭 링크는 확인하고 공통 원본만 편집한다.
5. 문서 이름 변경이나 이동 시 기존 라우팅도 수정한다. README나 인덱스 연결을 요구하는 프로젝트에서는 함께 갱신한다. 기존 규칙과 문서가 충돌하면 단순 링크로 덮지 말고 사용자의 확정된 결정에 맞는 범위를 정리한다.
6. 문서와 라우팅을 다시 읽고 링크 대상 파일과 필요한 절이 존재하는지, 상대 경로가 라우팅 파일 기준으로 맞는지, 후속 요청에서 읽어야 할 조건이 명확한지 확인한다. 같은 문서를 재차 갱신해도 라우팅이 중복되지 않아야 한다.
7. 해당 저장소의 커밋과 승인 규칙을 따른다. 외부 게시나 다른 저장소 변경 권한이 새로 생기는 것은 아니다. 완료 보고에는 문서와 AGENTS.md의 실제 링크를 짧게 남긴다. 접근 제한으로 라우팅하지 못하면 문서 저장과 라우팅 상태를 구분한다.

## 라우팅 예시

`- 로그인 버튼의 디자인이나 구현을 변경할 때는 [로그인 버튼 제약](docs/login-button-constraints.md)을 먼저 읽는다.`

규격 전체를 AGENTS.md에 복제하지 않는다. 목차만 담은 문서라면 이름만 링크하지 말고 필요한 절이나 하위 문서까지 찾을 수 있게 한다. 문서에서 미확인으로 남긴 내용을 라우팅 문장에서 확정 사실로 바꾸지 않는다.

## 전역 호출 연결

이 스킬은 암시적 호출을 허용한다. 전역 AGENTS.md의 작업별 지식 라우팅에는 다음 규칙으로 연결한다.

`- 지속 보관할 문서를 작성하거나 갱신할 때는 document-memory-routing 스킬을 적용해 문서 저장과 해당 프로젝트 AGENTS.md의 읽기 조건 및 경로 연결까지 함께 완료한다.`

이 자동 적용은 에이전트의 문서 작성 절차다. 외부 편집기의 저장 이벤트를 감시하는 훅이나 파일 감시 서비스는 설치하지 않는다.
